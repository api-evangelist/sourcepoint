# Sourcepoint Public API Documentation

> Sourcepoint offers your organization multiple APIs to manage end-user consent and vendor lists across multiple regulatory frameworks.

## API Reference
- [Welcome to the Sourcepoint API Hub](https://sourcepoint-public-api.readme.io/reference/welcome-to-the-sourcepoint-api-hub.md)
- [GDPR TCF end-user consent status](https://sourcepoint-public-api.readme.io/reference/gdpr-tcf-end-user-consent-status.md)
- [Get end-user consent status](https://sourcepoint-public-api.readme.io/reference/get_consent-v3-history-siteid-1.md): Returns end-user GDPR TCF consent status for a property. In addition to the `siteId`, you will also need to include <u>either</u> the end-user's `consentUUID` or `authId`.
- [Merge end-user consent status with identity provider](https://sourcepoint-public-api.readme.io/reference/post_consent-v3-siteid-tcstring.md): Merge an end-user's custom vendor consent profile with the information Sourcepoint has for IAB vendors taken from a TCString that is provided. Though originally planned for the German consortium *NetId*, it is available for any identity provider to confirm or revoke vendor consent in one place<br><br>*Your organization will require their own CMP ID to use this API. Please contact your Sourcepoint Client Support team if you require more information.*
- [Delete end-user consent status](https://sourcepoint-public-api.readme.io/reference/delete_consent-v3-siteid-1.md): Deletes end-user GDPR TCF consent status for a property. In addition to the `siteId`, you will also need to include <u>either</u> the end-user's `consentUUID` or `authId`.<br><br>This endpoint does not support mass deletions of end-user consent records. Please speak to your Sourcepoint representative to execute any mass deletions.
- [GDPR TCF vendor list](https://sourcepoint-public-api.readme.io/reference/gdpr-tcf-vendor-list.md)
- [Map vendors and purposes](https://sourcepoint-public-api.readme.io/reference/get_vendor-list-vendor-purpose-mapping-1.md): Returns mapping of vendors and purposes with legal bases for the vendor list associated with the property.  **Note**: *For each vendor, the response will only include purposes that have a configured legal basis (**Consent**, **Legitimate Interest**, **Disclosure Only**). Any purposes that are **Not Applicable** will not be returned in the response.*  *Additionally, vendors will need at least one purpose with a configured legal basis to be returned in the response.*
- [Vendor URL mapping](https://sourcepoint-public-api.readme.io/reference/post_vendor-list-vendor-url-mapping-1.md): Intended to be used by publishing systems to help determine if a vendor URL has been defined appropriately in the Sourcepoint system. This API can help developers that are integrating with Content Management Systems (CMS) verify that a URL referenced in content can be related to vendor and purpose consent preferences which can be queried and set based on user actions.<br><br>Before utilizing this API, ensure [vendor URL mappings are configured for the vendor](https://docs.sourcepoint.com/hc/en-us/articles/4403605562259#h_01H08080CKBEKA9KBF6AHFB1TC) in the Sourcepoint portal.
- [Retrieve vendors on vendor list](https://sourcepoint-public-api.readme.io/reference/get_vendor-list-vendors.md): Returns a list of vendors for the GDPR TCF vendor list associated with the specified property.
